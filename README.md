# Mood Chatbot 🤖

A mood-based AI chatbot built with Streamlit, LangChain, and Mistral AI.

## Features

- 😡 Angry AI Mode
- 😢 Sad AI Mode
- 😂 Funny AI Mode
- 💬 Conversational chat history
- 🎨 Clean Streamlit UI
- 🤖 Powered by Mistral AI

## Tech Stack

- Python
- Streamlit
- LangChain
- Mistral AI
- python-dotenv
